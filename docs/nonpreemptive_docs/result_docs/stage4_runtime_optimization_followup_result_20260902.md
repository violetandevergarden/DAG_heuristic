## 成本来源与门槛

统一 `DecisionContext` 使同一决策点的 ready、active、合法动作、tail 和下一事件只计算一次，并缓存单 channel children。阶段计时显示正常额外成本来自独立 trace 回放、合法性验证和前 128 个决策的多策略观测，而不是内存跟踪。

Stage 4d depth=0 已去掉未使用的候选生成，但包装入口相对 bare 的中位开销仍为 1.46--1.88 倍；原因是最终结果仍需独立验证，不能为达成性能数字删除验证。Stage 4e 应与 validated 而非 bare 比较；它走相同公共 LT 与验证路径。上述包装均保持 makespan 和动作摘要一致。

所有计划规模均低于 30 秒；本轮没有 timeout，因此“最后阶段”均为 `completed`，没有虚构超时位置。runner 已能在发生硬超时时从原子阶段标记中报告最后完成阶段、决策数、模拟时间及是否进入回放/验证。
