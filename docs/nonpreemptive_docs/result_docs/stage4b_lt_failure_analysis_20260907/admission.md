# Stage 4b：后续方向准入结论

日期：2026-09-07

## 证据范围

本轮覆盖正式 Stage 4f 的 9 图、两种模式、每个组合 32 个 LT 可达状态，共 576 个状态。获得 23 个条件改善、277 个平局、57 个变差和 219 个无不同挑战/未知标签。712 次已完成挑战回放全部 trace 合法，没有运行错误。

这些图已经用于算法设计，原有 development/validation/holdout 标签不能在下一轮继续解释为新的盲测。条件值均为一个完整首动作后接冻结 LT，不是 Exact；推广结论需要新增未参与设计的来源组。

## 4d：准入

4d 通过机制准入：23 个条件改善分布在 8 个正式 benchmark、5 个 source_group，optional-idle 14 个、work-conserving 9 个；至少一个真实来源存在可重复同状态修复，且全部完成 trace 合法。

优先测试 D1“LT 前两名+完整动作条件比较”。22/23 个改善状态的 tail 相对差距不超过 0.15，但该条件命中率低，必须保留完整补全确认。持续时间差异可作为第二个便宜过滤条件。

job 信息允许作为候选来源：23/23 个改善都发生跨 job 换向。主算法仍为 LT；job 剩余量不能直接覆盖 LT，因为大量 job 策略分歧只得到平局或退化。

D2“可靠未来释放+WAIT”暂不通过真实输入准入：576 个状态覆盖为零。先完成手算/Exact 测试并补充含确定释放结构的真实来源，再决定是否在线运行。

一步修正未覆盖完整策略优势。至少两个 GPT13/GPT7 work-conserving 图的完整固定 job 顺序明显优于 LT，但采样状态没有条件改善。4d 后续必须把端到端收益作为最终指标，并检查多步 job 服务顺序。

## 4c：有限准入

两个 routed 图的 work-conserving 状态共有 8 个条件改善，允许开展同源配对内的集合成员修正实验。当前替代动作的资源并集与 LT 集合相同，没有得到 one-for-two 资源脚印支持，因此只准入专门的 C1 候选构造与机制核对，不支持推广 packing 结论。

正式质量验证仍需新增独立 workload/topology 配对；optional-idle routed 状态本轮无条件改善，不能由 work-conserving 结果外推。

## 4e：不重新准入

61 个 last-missing 挑战中 0 个改善、53 个平局、8 个变差。现有数据未显示 barrier 相对 tail、duration、job 分歧有额外预测价值。4e 当前保留为反例与离线诊断，不进入权重调参、在线 rollout 触发或综合算法。

## 成本门槛

特征全轨迹扫描合计 114.73 秒；补充动作特征本身为 0.47 秒，重放状态为 49.17 秒。条件补全累计 1,897.78 秒，远高于特征计算，证明后续重点应放在减少补全调用。

计划的每状态 30 秒预算仅在补全之间检查。本轮有 12 次单次补全完成后才发现累计越过预算，最大状态用时 53.31 秒；这些结果本身完整且 trace 合法，但不能作为硬预算合规证据。4d 在线实验前必须让补全函数接收真正截止时间或放入可终止的独立进程，并把超时记 unknown 后回退 LT。

## 最终判断

- 进入 4d：D1 前两名修正；job 信息只辅助提出候选。
- 有限进入 4c：只做现有 routed 配对的合法集合机制实验。
- 暂缓 D2：真实可靠未来释放覆盖不足。
- 停止当前 4e 算法准入：last-missing 没有增益证据。

本结论是后续实验准入，不是最终算法收益结论。
